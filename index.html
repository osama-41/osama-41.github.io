Approach

Built the way a tester would build it.

I started in QA. Now I write the code, and I still think like the person trying to break it.

Own the feature, every layer

I take a feature from the requirement and the API design to the database, the app screen and the admin page, and ship it as linked pull requests across each repo.

Clean, modular code

Clean Architecture with MVI or MVVM, multi-module Gradle projects and a shared design system, so a team can change one part without breaking another.

Tested before it ships

Unit, UI, integration and Playwright end-to-end tests as I build, then regression and smoke tests on real devices before each release.

Safe releases

New behaviour ships behind flags that start off and are turned on in staging first. I use AI-assisted development to move faster, and I review and test every change.
